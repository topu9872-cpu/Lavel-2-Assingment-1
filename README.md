# TypeScript Assignment

## Overview

This repository contains my TypeScript assignment solutions. The assignment focuses on practicing core TypeScript concepts, including functions, type safety, interfaces, generics, tuples, classes, inheritance, and asynchronous programming.

## Topics Covered

1. **Optional Parameters:** Implemented a multiplication function with an optional multiplier and a default value.
2. **Unknown Type:** Used `unknown` with type checking to process different types of input safely.
3. **Readonly Tuple:** Used a readonly tuple to format geographic coordinates.
4. **Generics:** Created a generic function to concatenate arrays of different data types.
5. **Interfaces:** Defined a `Course` interface and filtered published courses based on student count.
6. **Keyof and Generics:** Used `keyof` and generic constraints to extract specific property values from objects.
7. **Classes and Inheritance:** Implemented `Employee` and `Manager` classes using inheritance, access modifiers, and getters.
8. **Promises and Async Operations:** Created an asynchronous age validation function using Promise, resolve, reject, and setTimeout.
